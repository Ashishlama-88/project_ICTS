Product Insight Sales:

Course/Programme: ICTS (Information & Communication Technology Skills)

Output: ICTS_product_insight.Rmd, ICTS_product_sales_insights.sql, product_sales_insights.sql


Overview :

This project analyses retail sales data combined with historical weather data to uncover insights into how weather conditions 
influence product sales. It focuses on the top 3 best-selling items (item numbers 5, 9, and 45) andbuilds predictive models using:

- Linear Regression

- Decision Tree Regression (rpart)

The workflow covers the full data science pipeline — from database extraction and cleaning, through exploratory data analysis (EDA) 
and visualisation, to model training, validation, and testing.
